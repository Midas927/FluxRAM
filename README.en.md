# FluxRAM

English | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

FluxRAM is a local Windows memory Boost tool. It focuses on freeing cold background working sets when you ask it to, or when memory pressure rises, while keeping protected apps such as games, creator tools, local AI workloads and streaming software out of the target list.

## Download

[Download the latest FluxRAM release](https://github.com/Midas927/FluxRAM/releases/latest)

Download `FluxRAM-Portable-Windows-x64.zip`, unzip it, and run `FluxRAM.exe`. FluxRAM and FluxRAM Pro use the same executable; Pro can only be activated with a key generated for the current machine ID.

## Editions

| Feature | FluxRAM | FluxRAM Pro |
| --- | --- | --- |
| Boost Now / Auto Boost | Yes | Yes |
| Light / Standard profiles | Yes | Yes |
| Extreme Performance profile | No | Yes |
| Add / remove protected apps | Yes | Yes |
| Pick protected apps from running processes | Yes | Yes |
| Process-name protection | Yes | Yes |
| Exact EXE path protection | No | Yes |
| Child-process association protection | No | Yes |
| Window recognition protection | No | Yes |

## Pro Activation

Open FluxRAM, copy the machine ID, and send it to sales or support. Enter the Pro Key you receive inside FluxRAM to activate Pro on that machine. The key is bound to the current computer.

There is no universal Pro installer and no public Pro key generation flow.
