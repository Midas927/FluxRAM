# FluxRAM

[English](README.en.md) | [简体中文](README.zh-CN.md) | 繁體中文 | [日本語](README.ja.md) | [한국어](README.ko.md)

FluxRAM 是一款面向 Windows 的本機內存 Boost 工具。它會在你需要時釋放冷背景進程佔用，或在內存壓力升高時自動處理，同時避開遊戲、創作軟體、本機 AI 和直播工具等受保護應用。

## 下載

[下載 FluxRAM 最新版](https://github.com/Midas927/FluxRAM/releases/latest)

推薦下載 `FluxRAM-Portable-Windows-x64.zip`，解壓後執行 `FluxRAM.exe`。普通版和 Pro 使用同一個程式；Pro 只能透過當前電腦機器碼 Key 啟用。

## 版本

| 功能 | FluxRAM | FluxRAM Pro |
| --- | --- | --- |
| 立即 Boost / 自動 Boost | 支援 | 支援 |
| 輕量 / 標準檔位 | 支援 | 支援 |
| 極致性能檔位 | 不支援 | 支援 |
| 新增 / 刪除受保護應用 | 支援 | 支援 |
| 從執行中進程選擇保護應用 | 支援 | 支援 |
| 進程名保護 | 支援 | 支援 |
| 精確 EXE 路徑保護 | 不支援 | 支援 |
| 子進程關聯保護 | 不支援 | 支援 |
| 視窗識別保護 | 不支援 | 支援 |

## Pro 啟用

開啟 FluxRAM，複製機器標識並交給銷售或客服。收到專屬 Pro Key 後，在 FluxRAM 內輸入即可啟用。Key 綁定當前電腦。

不提供通用 Pro 安裝包，也不提供公開 Pro 生成方式。
