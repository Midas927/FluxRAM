# FluxRAM 产品定位

## 目标定位

FluxRAM 是面向 Windows 普通用户、游戏用户和 Windows 掌机用户的低打扰内存 Boost 工具。

FluxRAM 不定位为完整的进程调度器，也不追求用复杂规则替代系统资源管理。核心价值是：

- 游戏或重负载前，清理冷后台占用。
- 内存压力上升时，自动执行克制的 Boost。
- 用可解释的策略告诉用户为什么裁剪或为什么不裁剪。
- 尽量避免影响前台应用、高 CPU / 高 I/O 进程和游戏相关进程。

## 竞品边界

### 对标 Mem Reduct

Mem Reduct 的用户心智是轻量、直接、内存清理。

FluxRAM 的差异点：

- 不只看释放量，还看候选风险。
- 更强调冷进程、后台进程和可释放收益。
- 提供候选预览和无裁剪原因。
- 更适合游戏前、掌机场景和普通用户低打扰使用。

### 对标 Process Lasso

Process Lasso 的用户心智是专业进程调度、CPU 响应性和规则自动化。

FluxRAM 不直接竞争完整 CPU 调度能力。FluxRAM 的边界是：

- 不做复杂优先级规则系统。
- 不默认调整进程优先级。
- 不承诺提升 FPS。
- 专注内存 Boost、保护策略、低打扰托盘工作流。

## 0.3.6 产品主线

0.3.6 的主线是“游戏/掌机友好”和“解释性”：

- 开机自启默认静默到托盘。
- 新增 Gaming / Handheld 档位。
- 内置游戏和掌机相关进程保护名单。
- 无裁剪时显示明确原因。
- 保持 Standard 稳定保守，避免为了释放数字制造卡顿。

## 对外话术

FluxRAM 不是暴力内存清理器，也不是 Process Lasso 替代品。它更像一个面向游戏前准备和日常内存压力场景的安全 Boost 工具：清理冷后台，避开活跃程序，并告诉用户每次为什么动或为什么不动。
