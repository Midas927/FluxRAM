# FluxRAM 产品定位

## 目标定位

FluxRAM 是面向 Windows 普通用户、游戏用户和 Windows 掌机用户的低打扰内存 Boost 工具。

FluxRAM 不定位为完整的进程调度器，也不追求用复杂规则替代系统资源管理。核心价值是：

- 游戏或重负载前，清理冷后台占用。
- 内存压力上升时，自动执行克制的 Boost。
- 用可解释的策略告诉用户为什么裁剪或为什么不裁剪。
- Pro 提供深度释放，让用户选择并确认关闭暂时不用的高占用应用。
- 尽量避免影响前台应用、高 CPU / 高 I/O 进程和游戏相关进程。

## 模式设计

0.3.6 后用户只需要理解三个模式：

- Daily：日常模式，最低打扰，适合办公、浏览器和普通使用。
- Gaming：默认推荐，适合游戏 PC 和 Windows 掌机，比 Daily 更积极，同时保护游戏平台、掌机控制中心和活跃进程。
- Extreme：Pro 专属，更强力，适合本地 AI、剪辑、直播、重负载游戏等场景。

不再把 Light / Standard / Gaming / Handheld 同时展示给用户。Standard / Balanced 作为旧设置迁移到 Gaming。

## 竞品边界

### 对标 Mem Reduct

Mem Reduct 的用户心智是轻量、直接、内存清理。

FluxRAM 的差异点：

- 不只看释放量，还看候选风险。
- 更强调冷进程、后台进程和可释放收益。
- 提供候选预览和无裁剪原因。
- Pro 提供深度释放，处理真正暂时不需要的高占用应用。
- 更适合游戏前、掌机场景和普通用户低打扰使用。

### 对标 Process Lasso

Process Lasso 的用户心智是专业进程调度、CPU 响应性和规则自动化。

FluxRAM 不直接竞争完整 CPU 调度能力。FluxRAM 的边界是：

- 不做复杂优先级规则系统。
- 不默认调整进程优先级。
- 不承诺提升 FPS。
- 专注内存 Boost、智能关联保护、深度释放和低打扰托盘工作流。

## 对外话术

FluxRAM 不是暴力内存清理器，也不是 Process Lasso 替代品。它更像一个面向游戏前准备和日常内存压力场景的安全 Boost 工具：清理冷后台，避开活跃程序，并告诉用户每次为什么动或为什么不动。需要更强力释放时，Pro 用户可以通过深度释放选择并确认关闭高占用应用。
