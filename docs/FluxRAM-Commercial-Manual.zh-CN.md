# FluxRAM 商业说明书

文档版本：1.0
更新日期：2026-05-07
适用对象：产品、销售、渠道、客户决策人

## 1. 产品定位

FluxRAM 是一款 Windows 本地内存 Boost 工具，面向游戏、本地 AI、剪辑、设计、开发等高内存压力场景。

产品核心不是“常驻疯狂清理”，而是 Boost-first：

1. 用户需要时点击 `Boost Now` 立即优化。
2. 用户也可以开启 `Auto Boost`，由程序在内存压力高时自动触发。
3. 受保护应用不会被清理，避免游戏、启动器、AI 推理、直播和创作软件被误伤。
4. 所有核心优化在本机执行，不依赖云端服务。

## 2. 版本策略

FluxRAM 采用“普通版足够好用，专业版解决高阶场景”的模式。

| 版本 | 定位 | 适合用户 |
| --- | --- | --- |
| FluxRAM | 免费普通版，覆盖大部分日常能力 | 普通游戏玩家、本地 AI 用户、普通办公和轻创作用户 |
| FluxRAM Pro | 付费专业版，提供更强策略和更精确保护 | 重度游戏玩家、直播/剪辑/设计用户、本地 AI 重负载用户、IT 管理场景 |

普通版应覆盖约 80%-90% 的常用体验，让用户免费使用也觉得完整；Pro 版重点提供更高级、更精确、更可控的能力。

## 3. FluxRAM 普通版能力

普通版包含：

1. `Light` 和 `Standard` 两种优化档位。
2. `Boost Now` 手动 Boost。
3. `Auto Boost` 内存压力触发 Boost。
4. 托盘常驻、托盘恢复、托盘 Boost、托盘退出。
5. 保护应用列表添加 / 删除。
6. 从正在运行的进程中选择保护应用。
7. 基础保护：按进程名跳过受保护应用。
8. Boost 后显示最近裁剪量、累计裁剪量、净收益、回弹率和自身开销。

普通版的目标是让用户不付费也能长期舒服使用。

## 4. FluxRAM Pro 能力

Pro 版在普通版基础上解锁：

1. `Extreme Performance` 极致性能档位。
2. 按完整 EXE 路径保护应用，避免同名进程误判。
3. 子进程关联保护，适合启动器、游戏客户端、AI 工具链和创作软件。
4. 智能关联保护，覆盖精确路径、子进程和进程名不稳定的关联应用。
5. 当前电脑永久激活，激活后无需联网验证。

Pro 版的价值不是把普通功能拿走，而是把“更强、更稳、更精确”的体验提供给高阶用户。

## 5. 授权流程

FluxRAM 启动后会展示当前电脑的机器 ID。

商业授权流程：

1. 用户把机器 ID 发给销售或客服。
2. 官方根据机器 ID 签发当前电脑专属 Pro Key。
3. 用户在 FluxRAM 内输入 Pro key。
4. 验证成功后，该电脑永久激活 FluxRAM Pro。

注意：

1. 客户只需要收到 FluxRAM 主程序和对应的 Pro Key。
2. 授权 key 绑定当前电脑，换电脑需要重新签发。

## 6. 对标 Mem Reduct

Mem Reduct 是成熟的 Windows 内存清理工具，用户心智明确：实时监控、清理系统缓存和 working set。

FluxRAM 的差异化方向：

| 维度 | Mem Reduct | FluxRAM |
| --- | --- | --- |
| 默认体验 | 实时监控与清理 | 手动 Boost + 压力触发 Auto Boost |
| 误伤控制 | 依赖用户配置清理区域 | 内置白名单、前台保护、冷却窗口、保护列表 |
| 可观测性 | 主要看内存变化 | 显示裁剪量、净收益、回弹率和自身开销 |
| 保护应用 | 不是核心卖点 | 普通版可添加/删除保护应用；Pro 支持高级保护 |
| 商业化 | 开源免费工具 | 免费版完整可用，Pro 面向高阶用户 |

FluxRAM 要做得更好用，关键是减少用户配置成本：不用手写进程名，一键添加保护应用，一键 Boost，压力高了自动处理。

## 7. 推荐卖点话术

简短版：

> FluxRAM 是一款 Windows 本地内存 Boost 工具。免费版已经包含手动 Boost、自动 Boost、保护应用列表和托盘体验；Pro 版解锁极致性能和高级应用保护，适合游戏、本地 AI、直播剪辑等高压力场景。

对重度用户：

> FluxRAM Pro 不只是清内存，而是尽量知道哪些应用不能碰。它通过精确路径、子进程和关联应用判断保护目标，让 Boost 更积极时仍然更可控。

对 IT/企业：

> FluxRAM 本地执行、无需云端遥测，支持固定机器授权，适合小范围试点和受控分发。

## 8. 交付建议

给普通用户：

1. `FluxRAM.exe`
2. 如使用 Small 包，再附带 `run-fluxram.bat` 和 `install-dotnet-desktop-runtime-8.bat`

给付费用户：

1. `FluxRAM.exe`
2. Pro key
3. 如使用 Small 包，再附带运行时安装脚本

运营注意：

1. Pro Key 只通过官方销售或客服流程签发。
2. 不向客户承诺跨机器通用授权。
