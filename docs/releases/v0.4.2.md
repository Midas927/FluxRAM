# FluxRAM v0.4.2

本次正式版让后台状态、内存变化和操作结果更清晰，并为更新与深度释放提供更多控制。

## 更新重点

- **更清晰的界面**：侧栏图标导航、环形内存仪表与最近两分钟的内存趋势，常用操作更集中；长条目自动换行，详情可选择、复制全文。
- **启动更新提醒**：发现新版本后，可选择立即更新、跳过此版本或稍后。跳过的版本会记住，选择稍后则本次运行不再重复提醒。
- **后台应用搜索**：按名称、路径查找应用，查看符合条件或被跳过的具体原因；Pro 深度释放也支持搜索。
- **应用收益观察**：记录本次运行中裁剪后 30、60、120 秒的工作集变化。内存未处于严重压力时，自动 Boost 会暂缓对反复低收益应用的重复裁剪。
- **更准确的判断与记录**：CPU 或磁盘活动采样不足时暂不裁剪；可用内存变化与工作集裁剪量分别显示，测量缺失时标明未知，跳过自动 Boost 时保留上次结果。
- **更可控的 Pro 深度释放**：显示批量处理进度，支持取消后续操作；应用未正常退出时，另行确认是否强制关闭，服务确认停止后才计入完成数量。取消不会撤销已执行的操作或恢复已关闭的应用，强制关闭可能丢失未保存内容。

## 版本区别

普通版与 Pro 的功能区别不变：普通版包含手动与自动 Boost、Daily / Gaming、应用搜索与收益观察；深度释放、后台服务建议与 Extreme 仍属于 Pro。

工作集裁剪量不等于系统可用内存的净增加量。实际结果取决于当前负载与保护设置，不承诺固定释放量。
