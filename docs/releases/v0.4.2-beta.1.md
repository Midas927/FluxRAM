# FluxRAM v0.4.2-beta.1

本地测试版，重点改善信息可读性、更新提醒与候选判断。

- **重新整理的界面**：左侧图标导航、环形内存仪表、实时曲线，优化操作集中排列；可用内存与工作集裁剪量分别标明。
- **真实内存趋势**：概览展示最近两分钟的负载变化，复用已有采样。
- **完整详情**：列表自动换行，可打开详情选择、复制全文。
- **侧栏显示修复**：选中背景与焦点边框完整显示，避免底部被截断。
- **启动更新提醒**：立即更新、跳过此版本、稍后三种选择；跳过版本会记住，稍后不会在本次运行中反复打扰。
- **更可靠的候选判断**：CPU/磁盘采样未知时暂不裁剪，防止误判空闲。
- **保留真实优化结果**：跳过自动 Boost 时不覆盖上一次释放数据。
- **准确记录结果**：无法取得测量数据时显示未知；服务真正停止后才计入完成数量。
- **可控的深度释放**：批量执行显示进度，支持取消后续操作；应用未正常退出时，单独确认是否强制关闭。
- **后台应用搜索**：按名称、路径查找应用，查看未进入候选的具体原因；深度释放也支持搜索。
- **应用收益观察**：查看本次运行中各应用在裁剪后 30/60/120 秒的工作集变化；自动 Boost 暂缓反复低收益的重复裁剪。

普通版与 Pro 的功能区别延续 0.4.1；深度释放与 Extreme 仍属于 Pro。
