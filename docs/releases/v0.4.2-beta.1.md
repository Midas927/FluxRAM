# FluxRAM v0.4.2-beta.1

本地测试版，重点改善信息可读性、更新提醒与候选判断。

- **更清晰的工作区**：概览、应用保护、最近活动、设置分开展示；可用内存与工作集裁剪量分别标明。
- **真实内存趋势**：概览展示最近两分钟的负载变化，复用已有采样。
- **完整详情**：列表自动换行，可打开详情选择、复制全文。
- **启动更新提醒**：立即更新、跳过此版本、稍后三种选择；跳过版本会记住，稍后不会在本次运行中反复打扰。
- **更可靠的候选判断**：CPU/磁盘采样未知时暂不裁剪，防止误判空闲。
- **保留真实优化结果**：跳过自动 Boost 时不覆盖上一次释放数据。

普通版与 Pro 的功能区别延续 0.4.1；深度释放与 Extreme 仍属于 Pro。
