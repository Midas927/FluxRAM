# FluxRAM v0.4.1

这是一次面向更新体验与详细界面可用性的修复版本。

## 更新重点

- **国内更新源**：程序内检查更新改用 GitCode 国内 Release，下载 Lite 或 Portable 对应版本时更稳定。
- **自动替换与清理**：下载后校验 SHA256，自动替换当前程序并重启；成功启动后删除旧 EXE 和本次更新缓存，失败时保留原程序。
- **滚动条恢复正常尺寸**：修复整个滚动轨道被压缩成短条的问题，滑块可以正常查看和拖动。
- **滚轮速度更自然**：详情页与内部列表使用统一的较缓步长，列表滚到边界后继续滚动外层。
- **完整条目详情**：受保护应用、Boost 明细和最近活动可通过双击或按 Enter 查看完整内容。

## 下载说明

- **Portable**：包含 .NET 8 Desktop Runtime，解压后直接运行。
- **Lite**：适合已经安装 .NET 8 Desktop Runtime 的电脑，功能与 Portable 相同。

FluxRAM 0.4 用户可以在程序内检查更新，也可以从 GitCode 国内镜像或 GitHub Releases 手动下载。
