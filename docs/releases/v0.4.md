# FluxRAM v0.4

这是一次面向实际后台占用与专业控制体验的大版本更新。

## 更新重点

- **深度释放成为主界面核心功能**：Pro 用户可直接检查并关闭确认不再需要的后台应用；普通版保留清晰的 Pro 功能入口与版本对比。
- **后台积累识别**：按应用族合并同一软件的多个零碎进程，持续观察窗口、CPU 与磁盘活动，区分闲置后台、后台工作中、有窗口和观察中。
- **小型驻留应用可见**：无窗口后台应用的展示门槛降至 12 MB，顶部汇总后台应用数量和累计内存。
- **更稳妥的推荐规则**：应用需持续观察至少 60 秒、取得至少 5 个样本且没有明显活动，才会标记为闲置；只有累计达到 96 MB 的闲置应用才可能预先勾选。
- **后台服务更易判断**：每条服务标记为系统服务或应用服务，并显示建议保留、不用该功能时可关、可随应用关闭等提示。
- **普通 Boost 识别更完整**：同一应用的子进程和后台组件合并计算，候选上限按应用而不是单个进程计算，并继续遵守前台、活动状态、应用保护和冷却规则。
- **Pro 应用保护增强**：精确路径、子进程和关联应用使用统一的智能关联保护，普通 Boost 与深度释放共享保护结果。
- **程序内更新完善**：支持下载对应 Lite/Portable 包、SHA256 校验、替换、重启，并在更新成功后清理旧程序和更新缓存。

## 下载说明

- **Portable**：包含 .NET 8 Desktop Runtime，解压后直接运行。
- **Lite**：适合已经安装 .NET 8 Desktop Runtime 的电脑，功能与 Portable 相同。

从旧版本更新后，建议让 FluxRAM 运行约一分钟，再打开深度释放查看完整的后台活动判断。
