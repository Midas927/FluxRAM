# FluxRAM

[English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | 日本語 | [한국어](README.ko.md)

FluxRAM は Windows 向けのローカルメモリ Boost ツールです。必要なとき、またはメモリ圧力が高いときに、冷えたバックグラウンドプロセスの working set を解放し、ゲーム、制作ツール、ローカル AI、配信ソフトなどの保護アプリを対象から外します。

## ダウンロード

[最新の FluxRAM をダウンロード](https://github.com/Midas927/FluxRAM/releases/latest)

`FluxRAM-Portable-Windows-x64.zip` をダウンロードして解凍し、`FluxRAM.exe` を実行してください。FluxRAM と FluxRAM Pro は同じ実行ファイルを使います。Pro は現在のマシン ID 向けに生成された Key でのみ有効化できます。

## エディション

| 機能 | FluxRAM | FluxRAM Pro |
| --- | --- | --- |
| 今すぐ Boost / 自動 Boost | 対応 | 対応 |
| 軽量 / 標準モード | 対応 | 対応 |
| 極限性能モード | 非対応 | 対応 |
| 保護アプリの追加 / 削除 | 対応 | 対応 |
| 実行中プロセスから保護アプリを選択 | 対応 | 対応 |
| プロセス名保護 | 対応 | 対応 |
| 正確な EXE パス保護 | 非対応 | 対応 |
| 子プロセス関連保護 | 非対応 | 対応 |
| ウィンドウ認識保護 | 非対応 | 対応 |

## Pro 有効化

FluxRAM を開き、マシン ID をコピーして販売またはサポートへ送ってください。受け取った Pro Key を FluxRAM に入力すると、その PC で Pro が有効化されます。

汎用 Pro インストーラーや公開 Pro Key 生成方法は提供しません。
