# FluxRAM Style Lock

## Direction

- Thesis: Windows memory management explained as a careful operating manual, not a flashy cleaner.
- First viewport: literal offer, GitCode domestic download, and one process-family observation visual.
- Macrostructure: editorial index with numbered operating beats.
- Selected concept: user selected ImageGen direction 2 on 2026-08-30.

## Color Contract

| Role | Value | Allowed use |
| --- | --- | --- |
| Paper | `#F7F8F6` | primary background |
| Surface | `#FFFFFF` | content surfaces |
| Ink | `#111D21` | primary text and evidence bands |
| Green | `#147A57` | primary action and safe state |
| Blue | `#315FAD` | observed state and secondary action |
| Orange | `#B85C2C` | caution only |
| Line | `#BDC8C1` | dividers and quiet borders |

Verified text-safe pairs: ink/paper, ink/surface, white/green, white/blue.

## Typography And Spacing

- Chinese sans stack: Noto Sans SC, Microsoft YaHei UI, Microsoft YaHei, PingFang SC.
- Technical labels: JetBrains Mono fallback Consolas.
- Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80.
- Corners: 4px for controls, 6px only on independent download choices.

## Motion

- Purposeful reveal only: opacity plus 16px translateY on scroll entry.
- Custom ease-out: `cubic-bezier(0.23, 1, 0.32, 1)`.
- Button press: scale 0.97, 140ms.
- Reduced motion removes transforms and preserves state visibility.

## Assets

- Use the real FluxRAM icon unchanged.
- Use generated process-family visual v2 in hero; no screenshot wallpaper.
- No decorative image is required for text-led ledger sections.
