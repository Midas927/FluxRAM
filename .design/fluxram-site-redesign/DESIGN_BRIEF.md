# FluxRAM Website Redesign Brief

## Product

FluxRAM 0.4 is a local Windows memory Boost utility. Ordinary Boost trims cold working sets without closing apps. Pro adds Deep Release, which groups fragmented background processes, observes activity, classifies optional services, and asks the user before closing anything.

## Audience

- Chinese Windows players and handheld-PC users who see many small background processes.
- Users with 8-32 GB RAM who want practical relief without trading stability for a larger number.
- Prospective Pro buyers comparing FluxRAM with Mem Reduct and Process Lasso.

## Primary Outcome

Build trust quickly and drive a safe download from the GitCode domestic mirror. GitHub remains a visible fallback.

## Secondary Outcomes

- Explain why FluxRAM is different from blind memory cleaners.
- Make ordinary Boost, Deep Release, and Pro edition boundaries easy to understand.
- Address SSD lifetime, FPS, unknown publisher, and low-yield concerns without defensive copy.

## Hard Constraints

- Static HTML, CSS, and JavaScript with no new framework dependency.
- Keep GitCode Portable as the primary CTA and GitHub as fallback.
- Keep Lite, SHA256, version comparison, and FAQ accessible.
- Preserve the FluxRAM icon and dark technical identity, but avoid a one-note green-black palette.
- No product screenshots as hero wallpaper, generic SaaS gradients, decorative blobs, nested cards, invented testimonials, or fabricated performance metrics.
- Responsive at 375, 768, 1280, and 1440 px; WCAG AA; visible focus; reduced-motion support.

## Design Read

- Artifact: product landing page and download hub.
- Mode: redesign overhaul with product and download contracts preserved.
- Visual language: precision instrument, Windows-native confidence, restrained editorial technology.
- Visual variance: 8/10.
- Motion intensity: 5/10.
- Information density: 6/10.
- Asset dependence: 3/10.
- Brand fidelity: 7/10.
- Signature element: a live memory-state field that explains active, protected, idle, and released memory without pretending to be Task Manager.

## Narrative

1. Name the product and offer a domestic download immediately.
2. Show what FluxRAM sees before it acts.
3. Explain ordinary Boost versus Deep Release.
4. Prove safety through exclusions, observation time, and user confirmation.
5. Compare Free and Pro without turning the page into a pricing wall.
6. End with download choices, checksums, and concise objections.
