# FluxRAM

[English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | 한국어

FluxRAM은 Windows용 로컬 메모리 Boost 도구입니다. 사용자가 요청할 때나 메모리 압력이 높아질 때 차가운 백그라운드 프로세스의 working set을 줄이고, 게임, 제작 도구, 로컬 AI, 스트리밍 소프트웨어 같은 보호 앱은 대상에서 제외합니다.

## 다운로드

[최신 FluxRAM 다운로드](https://github.com/Midas927/FluxRAM/releases/latest)

`FluxRAM-Portable-Windows-x64.zip`을 내려받아 압축을 풀고 `FluxRAM.exe`를 실행하세요. FluxRAM과 FluxRAM Pro는 같은 실행 파일을 사용합니다. Pro는 현재 PC의 기기 식별자에 맞춰 생성된 Key로만 활성화할 수 있습니다.

| 창 인식 보호 | 미지원 | 지원 |

## Pro 활성화

FluxRAM을 열고 기기 식별자를 복사해 판매 또는 지원 담당자에게 보내세요. 받은 Pro Key를 FluxRAM에 입력하면 해당 PC에서 Pro가 활성화됩니다.

공용 Pro 설치 파일이나 공개 Pro Key 생성 방식은 제공하지 않습니다.
