# FluxRAM

[English](README.en.md) | 简体中文 | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

FluxRAM 是一款面向 Windows 的本地内存 Boost 工具。它在需要时释放冷后台进程占用，并在内存压力升高时自动处理，同时避开游戏、创作软件、本地 AI 和直播工具等受保护应用。

## 下载

[下载 FluxRAM 最新版](https://github.com/Midas927/FluxRAM/releases/latest)

推荐下载 `FluxRAM-Portable-Windows-x64.zip`，解压后双击 `FluxRAM.exe`。普通版和 Pro 使用同一个程序；Pro 只能通过当前电脑机器码 Key 激活。

## 版本

| 功能 | FluxRAM | FluxRAM Pro |
| --- | --- | --- |
| 立即 Boost / 自动 Boost | 支持 | 支持 |
| 轻量 / 标准档位 | 支持 | 支持 |
| 极致性能档位 | 不支持 | 支持 |
| 保护应用添加 / 删除 | 支持 | 支持 |
| 从运行进程选择保护应用 | 支持 | 支持 |
| 进程名保护 | 支持 | 支持 |
| 精确 EXE 路径保护 | 不支持 | 支持 |
| 子进程关联保护 | 不支持 | 支持 |
| 窗口识别保护 | 不支持 | 支持 |

## Pro 激活

打开 FluxRAM，复制机器标识，发送给销售或客服。收到专属 Pro Key 后输入激活。Key 绑定当前电脑，更换电脑需要重新生成。

不会提供通用 Pro 安装包，也不提供公开 Pro 生成方式。
